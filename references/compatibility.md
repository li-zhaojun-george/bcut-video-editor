# 来源与兼容性

上游：https://github.com/LQH-A-A-O/dsh-bcut-edit

固定上游提交：`8cbd464976aa8babe2c88312eb915e4a15e3680a`，MIT；许可证保留在仓库根目录。上游面向 DSH 和必剪 3.10.x，本包使用其本地 Python 工具、格式模板和素材目录，并添加 Codex 适配；不安装 DSH。

## 兼容性修复

- FFmpeg 指向单个 exe 时，正确查找同目录 FFprobe。
- 按修改时间选最新草稿，避免跨午夜误读。
- 在工作区暂存工程，媒体及时间范围检查通过后才生成；注册时备份索引，保留原条目，拒绝覆盖已有 GUID。
- 音频素材表使用 itemType=5、帧率为 0；本地音轨使用 audioType=1，清除旧素材标记。
- 字幕内容由当前方案提供，补齐 speech 模板路径及画布矩形。
- 视频与字幕使用统一且不冲突的视觉轨道编号；字幕在视频之上，主轨 split=true，同步显示顺序。
- 移除旧模板 businessType=2 裁剪效果，使用空 propertyFxList。必剪 3.11 会把旧效果转换为零尺寸裁剪，导致错误码 7 / SDK 913。
- 支持原声音量和字幕 scale 设置。
- 模板不保留实例编号、历史导入时间、字幕正文、素材标题或缓存封面；加载模板时生成新实例编号。

## 已验证范围

Windows / 必剪 3.11.25.100：顺序视频裁剪拼接、可编辑中文字幕、本地音轨及淡入淡出通过原生导出检查。成片完整解码，字幕画面与音频信号已检查。

生成和注册的回归检查覆盖字幕层级、音频类型、静音、工具发现、时间范围、拒绝覆盖、运行中保护、索引备份及旧字段保留。两个临时配置的隔离测试检查新工程只引用对应配置的素材与资源。

隔离测试不使用真实媒体或运行必剪，不替代原生导出验收。高级转场、多轨叠加、变速和 FFmpeg 效果一致性未完成原生验收；其他必剪版本也需要重新验证。
