# 发布内容与数据隔离

发布包只包含源代码、格式模板、通用示例和文档。字幕模板不存正文；音视频模板不存素材名称、路径、剪辑标记或素材实例编号。实例编号在生成时创建，素材与字幕由当前方案提供。

示例方案使用演示文字和 `C:/Media/` 占位路径，需要替换后才能执行。必剪字体、speech 模板和可选内置资源在当前机器上解析；官方资源编号用于匹配素材目录，不是用户作品编号。内置资源目录不包含媒体文件。

Python 生成和注册脚本在本地读写，不实现媒体上传或账号登录。生成的草稿会包含使用者自己的媒体路径和字幕，这是必剪读取工程所需的数据；这些产物应放在工作区，不能混入公共仓库。

注册操作只新增 GUID，并备份索引、保留原条目。预览、导出结果及不同版本兼容性仍需验证，格式检查不代表对每个必剪版本都兼容。

发布前运行：

```powershell
python -X utf8 scripts/check_distribution.py
python -X utf8 -m unittest discover -s tests -v
```

分发检查会拒绝非预期文件、媒体/草稿、具体 Windows 用户目录和模板残留实例数据。隔离测试使用两个临时配置和合成元数据，检查素材路径、字体资源、实例编号及注册时的旧条目保留，不接触实际必剪草稿库。它们不代替人工审查字幕正文、说明文档或原生导出结果。

GitHub 仓库所有者、提交作者以及 MIT 版权声明属于公开项目归属信息，会正常保留。
